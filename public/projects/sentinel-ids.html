Machine learning for network intrusion detection

Sentinel IDS

A research prototype for classifying compatible network connection records and reviewing potential anomalies.

Built by Muhammad Saad Ahmed · View source on GitHub

Investigation workflow

A Random Forest model scores manual or batch connection records. Saved alerts, analyst notes and status changes support follow-up and review.

Evaluation and scope

The model was evaluated using NSL-KDD. Results describe performance on that benchmark. The prototype works on supplied connection records and has no live packet capture or blocking.

Technology

Python, Streamlit, scikit-learn and SQLite
