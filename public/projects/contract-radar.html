Contract-Radar

A smart contract security tool that links static analysis findings to source locations and remediation guidance.

Built by Muhammad Saad Ahmed · View source on GitHub

Review workflow

Contract-Radar combines Slither with custom detector classes. Compiler-aware checks use Solidity syntax trees and intermediate representations to identify issues for review.

Design decisions

Reports include severity, confidence and source evidence to help reviewers prioritize findings. The CLI and REST API support exports including JSON and SARIF. Static analysis supports manual review.

Technology

Python, Slither, SQLite and Docker
