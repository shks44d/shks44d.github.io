Socluma

A personal SOC platform that brings telemetry, detection rules and incident investigation into one workspace.

Built by Muhammad Saad Ahmed · View source on GitHub

Investigation workflow

Authenticated Windows and Linux collectors feed telemetry into the workspace. Sigma-style detections and MITRE ATT&CK mapping help organize alerts, and evidence timelines let an investigator trace an incident back to its source events.

Design decisions

Evidence-grounded AI assistance uses source context during investigations. Tenant isolation, granular permissions and audit logs help control and record access.

Technology

Python, FastAPI, React, PostgreSQL, Redis and Docker
